外部预测地址是什么？

这是你电脑上模型程序的接入口，不是 DeepSeek 的 API 地址。

例如：用 Python 写好一个模型，让它监听 http://127.0.0.1:9001/predict，再把该地址填入上方。

只填写地址还不够：对应的 Python 程序必须正在运行。终端会发送已收盘行情，程序返回“买入 / 做多、做空或等待”，仓位和风控仍由终端处理。

第一次使用：运行项目自带示例
  1. 在本程序所在文件夹打开终端；电脑需要已安装 Python。
  2. 执行 python examples/external_model_server.py，保留该终端窗口运行。
  3. 看到 Model adapter listening on http://127.0.0.1:9001/predict 后，将此地址填入“外部预测地址”。
  4. 保存模型，在下方“实时试算”检查连接，成功后才去现货 / 合约页选择它。

这个示例只演示通信，透传已有趋势条件；不是训练好的盈利模型。修改示例中的 predict() 即可接入自己的算法。关闭程序、端口占用或地址错误都会导致连接失败；此时不会新开仓。

让AI额外参考什么？可分别勾选，默认关闭

使用研究页已采集并解析、仍有效且关联当前币种的事件；保留原始来源和可用时间。没有有效数据时暂停新开仓。

使用当前币种与执行周期的研究模型，在最新已收盘行情上重新计算评分。支持1H / 4H；先在研究页重新训练。要求模型不超过7天，样本外至少100行、30笔交易；这些门槛不代表收益验证通过。

ML评分未经独立概率校准，不能当成胜率；研究持有方式与AUTO不同。来源缺失、过期或不匹配时不让AI补猜，已有止损与移动保护继续有效。

开启 AI 后，实时预览或 AUTO 每根新收盘 K 线会调用 API。只发送公开行情、模型配置，以及你勾选的公开事件和ML研究结果；不发送密钥、账户余额或持仓。AI会返回简短决策说明，在交易页“AI分析与信息来源”中查看。

参数保存后才会出现在交易页的模型选择器。
