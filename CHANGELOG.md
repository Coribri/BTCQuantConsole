# Changelog / 更新记录

## 1.0 - Initial publication / 首次发布

- Local charting workspace with paper spot, futures and grid workflows.
- Capability-aware exchange connections and a Binance spot order workflow.
- Explicit order previews, submission locking and durable receipt reconciliation.
- Research views and external local-model interfaces.
- Bilingual documentation and a Windows x64 package.

首个公开版本，提供本地行情与模拟工作区、交易所能力状态、现货订单确认和回执核对、策略研究界面，以及中英文说明与 Windows x64 发行包。
